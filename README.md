# Recruitment Pipeline & Interview Intelligence Platform (Backend)

## Overview

This project is a backend system designed to manage the complete recruitment lifecycle — from job creation to candidate hiring.

It focuses on building a scalable, production-ready architecture using modern backend technologies and clean design principles.

## Tech Stack

* NestJS
* TypeScript
* TypeORM
* PostgreSQL
* Docker
* Swagger

## Features (In Progress)

* Role-based access control (Admin, Recruiter, Interviewer, Hiring Manager)
* Job opening management
* Candidate management
* Application tracking with stage transitions
* Interview scheduling and feedback system
* Decision and offer workflow

## Project Structure

Follows a modular, enterprise-style architecture with clear separation of:

* application layer (use-cases, DTOs)
* domain layer (entities, enums)
* infrastructure layer (repositories)
* presentation layer (controllers)
